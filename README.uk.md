> **Мова:** [English](README.md) | **Українська**

## Мета роботи

Метою роботи є розробка повнофункціонального шахового рушія на мові C, що запускається в командному рядку Linux. Програма демонструє застосування низькорівневих технік програмування: бітових дощок (bitboards) для представлення шахової позиції, магічних бітових дощок для ходів фігур, що ковзають, а також хешування Зобриста для визначення повторень позиції. Програма виконує перевірку системних викликів та коректно завершує роботу у всіх граничних випадках.

---

## Опис реалізації

Проєкт складається з шести модулів:

### `src/main.c` — Точка входу та ігровий цикл
Ініціалізує всі підсистеми (початкову позицію, таблиці ходів коней, магічні бітові дошки, ключі Зобриста). Реалізує основний ігровий цикл: зчитує хід від користувача у форматі LAN (Long Algebraic Notation), перевіряє його коректність та легальність, виконує хід і визначає стан гри (мат, пат, нічия).

### `src/move.c` — Генерація та виконання ходів
Реалізує генерацію всіх псевдолегальних і легальних ходів для кожного типу фігур за допомогою бітових операцій. Підтримує рокіровку, взяття на проході та перетворення пішаків.

### `src/magic.c` — Магічні бітові дошки
Передобчислює атакуючі таблиці для тур і слонів за алгоритмом магічних бітових дощок, що дає O(1) доступ до ходів фігур, що ковзають, у будь-якій позиції.

### `src/zobrist.c` — Хешування позиції
Генерує унікальний 64-бітний хеш для кожної позиції (враховує розміщення фігур, право на рокіровку, поле взяття на проході, чергу ходу). Використовується для виявлення повторень позиції.

### `src/print.c` та `src/position.c` — Виведення та ініціалізація
Виводить шахову дошку в термінал з кольоровим ANSI-оформленням та символами Unicode для фігур. Ініціалізує початкову позицію за допомогою бітових масок.

## Використані системні виклики

Програма використовує наступні системні виклики (безпосередньо або через стандартну бібліотеку C):

| Системний виклик | Функція libc | Де використовується | Опис |
|---|---|---|---|
| `write` | `printf` | `print.c`, `main.c` | Виведення шахової дошки, повідомлень про стан гри та підказок у стандартний вивід (`stdout`, fd=1) |
| `read` | `scanf` | `main.c` | Зчитування ходу від користувача зі стандартного вводу (`stdin`, fd=0) |
| `brk` / `mmap` | неявно через `libc` | ініціалізація | Виділення пам'яті для статичних таблиць (магічні бітові дошки, таблиці ходів) |
| `exit_group` | `return` з `main` | `main.c` | Коректне завершення процесу після команди `q` або закінчення гри |

## Збірка та запуск

### Вимоги
- Linux (Ubuntu 20.04+)
- GCC або Clang
- CMake >= 3.10

### Кроки збірки

```bash
git clone https://github.com/Andrew3378o/cchess.git
cd cchess
mkdir build
cd build
cmake ..
make
./cchess
```

## Поточні можливості

- **Бітові дошки:** представлення позиції через 64-бітні цілі числа для швидких порозрядних операцій
- **ANSI-інтерфейс терміналу:** кольорові клітинки та символи Unicode для фігур
- **Генерація ходів:** усі легальні ходи для кожного типу фігур, включно з рокіровкою та взяттям на проході
- **Парсер введення:** перетворення рядків LAN у внутрішнє представлення ходу
- **Детекція шаху, мату та пату:** визначення кінцевих позицій
- **Нічия:** нічия при повторенні позиції та недостатньому матеріалі
- **Хешування Зобриста:** ефективне хешування позиції для детекції повторень

## Висновок

У ході виконання роботи було розроблено повнофункціональний шаховий рушій на мові C, що запускається в командному рядку Linux. Реалізовано такі ключові компоненти: бітові дошки для швидкого представлення шахової позиції, магічні бітові дошки для генерації ходів фігур, що ковзають, та хешування Зобриста для виявлення повторень позиції.

Програма коректно обробляє помилки введення (невалідний формат ходу, нелегальний хід, EOF) та завершує роботу в усіх граничних випадках. Для взаємодії з операційною системою використовуються системні виклики `read` (через `scanf`) та `write` (через `printf`), їхні повернені значення перевіряються в кожній критичній точці.

Проєкт демонструє ефективне застосування низькорівневих технік програмування на C у системному середовищі Linux.
